# agenda-contatos
Aplicação en Python, feita em dupla, para cadastrar, listar, buscar e remover contatos via terminal.
## funcionalidades
- Cadastrar um novo contato (nome, telefone e email)
- Listar todos os contatos cadast:ados
- Buscar um contato pelo nome
- Remover um contato

## Como executar
```
python agenda . py
```
